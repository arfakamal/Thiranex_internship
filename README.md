# 🎓 CampusConnect

### Your College Companion

CampusConnect is a **college mobile app wireframe concept** designed to help students access their daily college information in one place.

The main idea is to make it easier for students to check their **timetable, attendance, assignments, announcements, and profile** without using multiple sources.

---

##  About the Project

This project is an **early-stage UI/UX wireframing project** created to understand the basic design and layout of a college companion mobile application.

The wireframe focuses on keeping the app **simple, clean, and easy to use** for college students.

---

##  Problem

Students often get college information from different places such as:

* WhatsApp groups
* Notice boards
* College portals
* Emails

Because of this, students may find it difficult to keep track of their **classes, attendance, assignments, and announcements**.

---

##  Solution

CampusConnect brings the important college information into **one simple mobile app**.

### Main Features

*  Timetable
*  Attendance
*  Assignments
*  Announcements
*  Student Profile

---

##  Wireframes

The project currently contains low-fidelity wireframes for the following screens:

1. **Login Screen**
2. **Dashboard**
3. **Attendance**
4. **Assignments**
5. **Profile**

The wireframes show the basic layout, navigation, buttons, and content placement of the application.
